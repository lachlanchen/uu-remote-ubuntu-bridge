# UU Remote Ubuntu Bridge

**Просмотр и полноценное управление рабочим столом Ubuntu GNOME через NetEase UU Remote.**

Этот экспериментальный мост запускает официальный Windows-клиент в отдельном
префиксе Wine и передаёт существующий рабочий стол GNOME через локальный RDP
или дополнительный локальный VNC-ретранслятор для X11.

Базовая среда — x86-64 Ubuntu 24.04, GNOME 46 и Wine 11. Новые установки используют проверенный UU `4.42.1.2835` с точными хешами и записями приёмки. Обычная переустановка сохраняет установленную версию. Неизвестные двоичные файлы не исправляются.

## Что работает

Проверено **2026-10-04**. Управление рабочим столом, текстовый буфер обмена и
диктовка работают на проверенных или подтверждённых пользователем маршрутах.
Это не гарантия для всех устройств, раскладок и функций Windows-клиента UU.

| Функция | Статус | Область проверки и ограничения |
| --- | --- | --- |
| Существующий рабочий стол Ubuntu | Работает | Видео и переподключение сохраняют выбранный сеанс и открытые приложения. |
| Мышь | Работает | Перемещение, щелчки, кнопки, колесо и фокус на проверенных маршрутах. |
| Физическая клавиатура / сочетания клавиш | Работает, зависит от клиента | Буквы, модификаторы и символы; без общей гарантии для всех раскладок US/JIS/Mac. |
| Клавиатура телефона / Unicode | Работает на проверенных маршрутах | Китайский текст, пунктуация, эмодзи и несколько строк; каждый IME требует отдельной проверки. |
| Непрерывная диктовка | Подтверждена в работе, есть регрессионные тесты | Исправления текущего ввода сохраняют прежние сообщения; проверки реальных телефонов различаются по версиям. |
| Текстовый буфер в обе стороны | Работает, зависит от маршрута | Только текст. Обратный канал X11/VNC включается отдельно, до 60 KiB; без изображений и файлов. |
| Один рабочий стол через UU / RDP / RealVNC | Дополнительная настройка | Общий физический X11-бэкенд; стандартные отдельные сеансы не объединяются автоматически. |
| Разрешение / размер области захвата | Настраивается | Фиксированный размер или следование стабильному размеру X11/VNC; не дополнительные виртуальные мониторы. |
| Восстановление / автозапуск | Условно | Контролируемый перезапуск и сохранение входа; необходимы рабочий вход GNOME и хранилище ключей. При приёмке 4.42 заново не проверяли перезагрузку компьютера. |
| Родной терминал UU → оболочка Ubuntu | Адаптер работает, канал условный | UTF-8 и размер PTY; остаются ограничения версий, соединения и родного кода завершения. |
| `uu-shell` | Проверен с настроенным SSH | Явный выбор LazyTunnel, SSH через перенаправление или родного терминала; успех SSH не доказывает работу родного канала UU. |
| Перенаправление портов UU / SSH / SCP | Условно | Есть успешные проверки; перехват управления или закрытие несущего соединения может разорвать канал. Это не VPN. |
| Super Screen / дополнительные виртуальные дисплеи | Не проверено | Нет приёмки для Ubuntu-моста; обычное изменение размера ничего не доказывает. |
| Защита от подглядывания / приватный экран | Не проверено | Нет проверенного Linux-бэкенда для скрытия физического экрана и блокировки локального ввода. Не полагайтесь на него для защиты приватности. |
| Звук / микрофон | Ограниченно | Зависит от хоста; некоторые установки намеренно используют беззвучный бэкенд. |
| Родная передача файлов, буфер изображений/файлов и прочие функции | Не проверено | Копирование текста не передаёт файлы; SCP/SFTP через проверенный SSH — отдельная возможность. |

См. [доказательства и ограничения](../docs/features.md), а также отдельные записи
[RDP](../docs/releases/4.42.1.2835-acceptance.md) и
[X11](../docs/releases/4.42-x11-workstation-20261001.md). Проверка Mac-контроллера
4.42 не включала непрерывную диктовку с реального телефона. Буфер общего рабочего
стола через XRDP 0.9.24 также имеет документированное ограничение для эмодзи вне BMP.

Для уже настроенного узла с именем `lab`:

```bash
uu-shell --list
uu-shell lab
uu-shell --lazy lab hostname
uu-shell --native lab
```

Замените `lab` именем своего профиля. `--lazy` требует регистрации LazyTunnel;
`--native` запрашивает собственный терминал UU и может независимо отказать.
Скрытого переключения транспорта или перехвата рабочего стола нет. [Подробнее](../docs/fleet-shell.md).

## Быстрая установка

```bash
./install.sh
```

Новая установка использует проверенный манифест **4.42.1.2835**; обычная переустановка сохраняет установленную версию. Закреплённая ссылка на FreeRDP nightly сейчас возвращает 404, поэтому для новой установки с RDP нужен существующий клиент с точно совпадающим хешем. На рабочем столе X11/XRDP команда `./install.sh --desktop-relay vnc` позволяет обойти эту зависимость. См. [восстановление загрузок и удаление дублирующих ярлыков с резервным копированием](../docs/fresh-install-recovery.md).

Идемпотентный установщик ставит зависимости, проверяет хеши, собирает
компоненты совместимости, настраивает GNOME Remote Desktop, хранит пароль RDP
в GNOME Keyring и запускает пользовательскую службу systemd.

## Путь управления

```text
Контроллер UU -> UU в Wine -> брокер ввода -> SDL FreeRDP
              -> GNOME Remote Desktop -> рабочий стол GNOME Wayland
```
