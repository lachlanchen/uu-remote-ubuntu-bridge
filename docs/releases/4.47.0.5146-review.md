# UU 4.47.0.5146 compatibility review

Reviewed on 13 November 2026 for Ubuntu 24.04, Wine 11 and a shared physical
X11 desktop with a private native-VNC relay. The manifest approves the exact
binary; it does not authorize unattended promotion on other hosts. Older
manifests and the fresh-install default remain unchanged.

## Download identity

The official endpoint advertised 4.47.0.5146, but its redirected GET returned
an installer identifying itself as 4.45.1.4372. That download was rejected.
The explicit official CDN URL in the manifest returned 4.47.0.5146 in the
installer, server, GUI and CLI PE resources. Saved filenames are insufficient.

The updater now rejects changed GET URL/version metadata, changed declared

drift; PE inspection and exact-hash acceptance remain necessary.

## Reviewed input and clipboard changes

The virtual-input Boolean moved from object offset `0x268` to `0x270`.
PE exception records bound these functions; setting/string references identify
their purpose. Three unrelated masked setter matches were excluded.

| Server file offset | Function RVA range | Change |
| --- | --- | --- |
| `0x5aa857` | `0x5ab0d0..0x5ab7fb` | Zero the constructor argument stored at `+0x270`, also read for `virtual switch state:`. |
| `0x588ae2` | `0x589580..0x589708` | Return false from the `global/virtual_mouse_switch` reader. |
| `0x588b94` | `0x589770..0x58999d` | Store false through the matching setter. |

The vendor's SendInput path is retained; authentication is unchanged. Patching
a disposable server copy and restoring it reproduced its original hash.

The [mobile clipboard repair](../outbound-mobile-unicode-clipboard.md) remains
necessary. The mobile export asks for ANSI text and queues it to another thread
for ANSI decoding. The guard supplies UTF-8 only for that reviewed export and
matches the queued bytes before decoding them as UTF-8. Normal ANSI consumers,
incoming dictation and the global Wine code page remain unchanged.

`src/uu_clipboard_builds.h` retains separate metadata and instruction signatures
for 4.44.1 and 4.47.0. Unknown builds are rejected. The new GUI timestamp is
`0x6af5bb16`, image size `0x466e000`, and return RVAs are:

| Boundary | RVA |
| --- | --- |
| Mobile export calls clipboard reader | `0xf8a179` |
| Reader calls GetClipboardData | `0xf888a3` |
| Queued callback requests ANSI decoding | `0x2dcd1b` |
| MultiByteToWideChar size query / output | `0x1a26263` / `0x1a262a0` |

## A restart defect: two processes with the same name

UU's outer launcher and real GUI are both named `GameViewer.exe`. Selecting
the first basename match at startup could load the guard into the launcher,
which correctly rejected that unrelated executable. Manual attachment later
worked because the launcher had exited. A stopped-prefix backup exposed this
difference between live attachment and a fresh start.

The injector now accepts an exact executable path. Clipboard startup targets
`GameViewer/bin/GameViewer.exe`, with bounded retries while that process is
absent. A disposable Wine test runs two identically named processes and proves
that only the requested path receives the DLL. Missing paths fail without
falling back to the launcher. The corrected candidate passed a fresh start
with the canonical guard loaded and a new success receipt.

## Qualification

Tests use isolated input targets; they do not type into working applications.

| Feature | Evidence in this review |
| --- | --- |
| Rapid key delivery | 2,052 ordered X11 transitions; 2,000-record broker batch. |
| Chinese, Japanese, emoji and punctuation | Semantic Unicode and multiline fixtures passed. |
| Continuous dictation | Revision/interleaving tests preserve earlier text; 2,000-character input arrives in one paste. Real microphone/client acceptance is separate. |
| Mouse and geometry | Isolated coordinate/button tests passed; physical/private canvas both 1920×1080. |
| Cursor | Guard enabled with a fresh server receipt; actual client rendering requires a controller check. |
| Incoming text clipboard | Ownership filtering, initial-content suppression, Unicode delivery and cleanup passed. |
| Outgoing text clipboard | Native cross-thread/out-of-order conversion, exact matching, bounds and unknown-build rejection passed for both builds. Live startup passed. |
| Terminal adapter | Authentication rejection, native shell, Unicode output and 24×80 resize passed. Vendor terminal UI availability is separate. |
| Login and signaling | Candidate reports 4.47.0.5146, logged in, service running, network connected and no last error. |
| Desktop and independent access | Physical desktop/VNC relay retained; RDP, RealVNC and SSH service PIDs unchanged. |
| Proprietary updater containment | Guard blocks the vendor updater while permitting ordinary Wine execution. |

The candidate was installed without network access into a complete copy of a
stopped signed-in prefix. Login registry and account-cache digests matched
before its first launch. The newly generated installer log was preserved
separately before comparison; existing account files were not excluded or
rewritten. Automatic rollback restored the old installation when the initial
clipboard startup check failed. The corrected candidate passed the same gate.

The corrected candidate also kept the same server process for 270 seconds.
It was then promoted to the normal prefix and passed another cold-start quick
verification, including exact runtime digest, patched server hash, local IPC
and a fresh outgoing-clipboard guard receipt. All 65 original desktop windows
were still present. The existing bridge and physical-VNC units remained
enabled, with user lingering enabled. No operating-system reboot was performed.

The automated suite completed 266 tests with seven optional integrations
skipped; the clipboard, injector and relevant input/terminal integrations were
also run explicitly. Phone-side acceptance of this new version remains pending;
the earlier confirmed 4.44 phone test is not treated as a 4.47 result.

Super Screen, the vendor anti-peep button, image/file clipboard and native
file transfer remain unverified. Audio remains deliberately disabled on this
host. Port-mapped SSH depends on its carrier and peer availability. See the
[feature matrix](../features.md); text-clipboard tests do not prove these extras.

## Reproduce and deploy

```bash
./scripts/build-compat.sh
python3 -m unittest discover -s tests -v
UURB_TEST_WINE=1 python3 -m unittest discover -s tests -p test_clipboard_guard.py -v
UURB_TEST_WINE=1 python3 -m unittest discover -s tests -p test_injector_targeting.py -v
./scripts/test-x11-phone-text.sh
./scripts/test-x11-clipboard-text.sh
./scripts/test-x11-mouse.sh
./scripts/test-controller-clipboard.sh
./scripts/test-terminal-bridge.sh
./scripts/test-vendor-updater-guard.sh
./scripts/verify.sh
```

Follow the [login-preserving upgrade procedure](../reusable-upgrade.md). Retain
a complete private prefix backup and independent SSH/RDP access, qualify the
candidate, and keep rollback until production-path checks pass. Installers,
prefixes and account state must stay outside Git. This manifest deliberately
has no automatic-promotion acceptance object.

Boot persistence depends on the enabled units and a usable GNOME login/keyring.
A service restart does not establish a tested operating-system reboot.
